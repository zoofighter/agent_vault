# 11개 섹터 심층 분석

> 각 섹터의 투자 논거, 지금 중요한 이유, 추적할 신호, 관련 기업을 정리한다.
> 메르 스타일 리포트 작성의 기준점으로 사용한다.

```
       [AI 인프라 수요]
            │
    ┌───────┴────────┐
    ▼                ▼
[반도체]          [에너지/전력]
(GPU·HBM)     (데이터센터 전력)
    │                │

    │
    ▼

[2차전지] ────── 전기차 + ESS + 드론 공통 기반

[양자컴퓨팅] ─────── 암호·AI 가속의 장기 게임
```

## 1. AI

### 투자 논거

AI는 섹터가 아니라 **모든 섹터를 관통하는 인프라**다.
클라우드 → 엣지 → 물리 세계(로봇·자동차)로 확산 중.
지금은 인프라 구축 단계(GPU·데이터센터)에서 응용 수익화 단계로 전환 중.

### 지금 중요한 이유

- 추론(Inference) 비용 경쟁 심화 → 누가 더 싸게 AI를 제공하는가
- AI 에이전트 시대 → 단순 챗봇 → 자율 실행 에이전트
- 온디바이스 AI → 스마트폰·PC로 확산 → 엣지 반도체 수혜

### 추적할 신호

| 신호 | 의미 |
|------|------|
| NVIDIA GB300/Blackwell 수주잔고 | AI 투자 사이클 지속 여부 |
| OpenAI·Anthropic 월간 ARR | 수익화 속도 |
| 클라우드 3사 AI 매출 비중 | AWS·Azure·GCP 전환 속도 |
| 에너지 소비 효율(FLOPS/W) | 다음 세대 칩 선택 기준 |

### 관련 기업 (볼트 내)
NVIDIA, Microsoft, Alphabet, Google, Amazon, Meta, OpenAI, Anthropic

### 데이터 소스
Hacker News API, NVIDIA·Meta AI 뉴스룸 RSS, Google News RSS

## 2. 반도체

### 투자 논거

AI 수요로 반도체 사이클이 구조적으로 바뀌었다.
과거: PC·스마트폰 교체 주기에 연동된 주기적 산업
현재: AI 데이터센터 신규 투자가 만들어내는 **비주기적·구조적 수요**

### 지금 중요한 이유

- **공정 경쟁**: TSMC 2nm vs 삼성 SF2 — 수율이 모든 것을 결정
- **패키징 병목**: CoWoS·HBM·SoIC — AI 칩 출하량의 실제 제약
- **장비 독점**: ASML EUV 없이는 선단 공정 불가능 — 지정학 변수
- **레거시 공정**: 28nm 이하 중국 내재화 진행 중 — 공급 과잉 리스크

### 추적할 신호

| 신호 | 의미 |
|------|------|
| TSMC CoWoS 캐파 증설 속도 | AI 칩 실제 공급 병목 |
| 삼성 GAA 수율 개선 소식 | 파운드리 2위 경쟁력 회복 여부 |
| ASML High-NA EUV 납품 일정 | 2nm 이후 공정 준비 상태 |
| HBM 가격·수급 | SK하이닉스·삼성·마이크론 경쟁 |
| SMIC·화웨이 장비 우회 시도 | 지정학 리스크 |

### 관련 기업 (볼트 내)
삼성전자, SK하이닉스, TSMC, ASML, Intel, AMD, NVIDIA, Micron, ARM, Qualcomm, MediaTek, Broadcom, Tokyo Electron, Nanya

### 데이터 소스
The Elec RSS, 전자신문 RSS, Hacker News API, Samsung Newsroom

## 3. 에너지/전력

### 투자 논거

AI 데이터센터가 **전력망의 새로운 수요 충격**이 됐다.
미국 전력 수요는 2024년 이후 수십 년 만에 처음으로 증가세로 전환.
전력 인프라 투자 사이클이 반도체 사이클과 동기화.

### 지금 중요한 이유

- 데이터센터 전력 수요: 2030년까지 현재의 3~4배 예상
- **원전 르네상스**: Microsoft·Google·Amazon이 SMR·기존 원전과 직접 계약
- 전력망 노후화: 미국·유럽 송전망 교체 사이클 시작
- ESS(에너지저장): 재생에너지 변동성 완충 → 배터리 수요와 직결

### 추적할 신호

| 신호 | 의미 |
|------|------|
| 빅테크 PPA(전력구매계약) 체결 | AI 전력 수요 확인 지표 |
| SMR 인허가 일정 (NRC) | 원전 르네상스 실현 시점 |
| 전력망 장비 수주잔고 (Eaton·Siemens·LS일렉트릭) | 인프라 투자 사이클 |
| 천연가스 LNG 가격 | 전력 단가 결정 변수 |

### 관련 기업 (볼트 외 주목)
Constellation Energy, Vistra, GE Vernova, Eaton, LS일렉트릭, 한국전력

### 데이터 소스
IEA API, FRED API, 연합뉴스 RSS, Google News RSS

## 4. 원자력 (에너지 하위 섹터)

### 투자 논거

탈탄소 + AI 전력 수요의 교차점.
간헐성 없는 24/7 탄소중립 전원으로 재평가.
빅테크가 직접 원전 계약하는 새로운 수요 구조.

### 지금 중요한 이유

- Microsoft: Three Mile Island 원전 재가동 계약
- Google: Kairos Power SMR 7기 계약
- Amazon: Dominion Energy 원전 전력 구매
- 한국: APR1400 수출(체코·폴란드), SMR 기술 개발

### 추적할 신호

| 신호 | 의미 |
|------|------|
| 미국 NRC SMR 인허가 일정 | 상용화 시점 |
| 우라늄 현물가격 (U₃O₈) | 원전 경제성 변수 |
| 한국 수출 원전 프로젝트 진행 상황 | 국내 원자력 관련주 |
| 폐쇄 원전 재가동 신청 건수 | 수요 강도 |

### 데이터 소스

## 5. 2차전지

### 투자 논거

EV 성장 둔화 우려에도 **ESS 수요가 빠르게 보완**하고 있다.
소재 기술(LFP vs NCM vs 나트륨이온)이 시장 구도를 재편 중.

### 지금 중요한 이유

- **LFP의 역습**: 중국 CATL의 LFP가 NCM 시장 침식 → 한국 배터리사 마진 압박
- **ESS 성장**: 재생에너지 + 데이터센터 전력 안정화 수요 폭발
- **소재 내재화**: 포스코·에코프로 양극재 → 수직통합 경쟁
- **전고체 배터리**: 2027~2028 양산 목표 — 토요타·삼성SDI 경쟁

### 추적할 신호

| 신호 | 의미 |
|------|------|
| 리튬·코발트·니켈 현물가격 | 소재 원가 압박 |
| CATL 유럽 공장 가동률 | 한국 배터리사 경쟁 강도 |
| 미국 IRA 보조금 정책 변화 | 미국 시장 경쟁 구도 |
| ESS 수주 공시 | 수요 전환 속도 |

### 관련 기업 (볼트 내)
LG에너지솔루션, 포스코홀딩스, CATL, BYD

전자신문 RSS, IEA API, DART (공시), Google News RSS

## 6. 바이오

### 투자 논거

AI가 신약 개발 사이클을 단축하고 있다.
GLP-1(비만치료제) 수퍼사이클은 10년 이상 지속 가능.
CDMO(위탁생산) 업황이 빅파마 R&D 아웃소싱과 연동.

### 지금 중요한 이유

- **GLP-1 경쟁**: Eli Lilly vs Novo Nordisk, 경구용·주간 1회 제형 경쟁
- **AI 신약**: AlphaFold 이후 단백질 구조 기반 신약 탐색 가속
- **ADC(항체약물접합체)**: 차세대 항암제 — 국내 레고켐바이오 등 수혜
- **임상 3상 결과**: 시가총액 50% 단기 등락 → 일정 추적 필수

### 추적할 신호

| 신호 | 의미 |
|------|------|
| FDA 패스트트랙·우선심사 지정 | 파이프라인 가치 상승 |
| 임상 3상 1차 평가변수 결과 | 주가 단기 급등락 |
| 빅파마 M&A (인수 대상 선정 기준) | 소형 바이오 프리미엄 |
| GLP-1 처방 데이터 (IQVIA) | 시장 침투율 |

### 관련 기업 (볼트 내)
Eli Lilly

### 데이터 소스
Google News RSS, 연합뉴스 (국내 임상), ClinicalTrials.gov (무료 API)

## 8. 디스플레이

### 투자 논거

OLED가 프리미엄 시장을 장악했고,
MicroLED·QD-OLED가 차세대 고가 시장을 놓고 경쟁 중.
AI PC·스마트폰 교체 수요가 OLED 출하량에 직결.

### 지금 중요한 이유

- **OLED 스마트폰**: 삼성·LG가 중국(BOE·CSOT) 추격을 얼마나 막는가
- **IT OLED**: 노트북·태블릿 OLED 확대 → 삼성디스플레이 중형 라인 가동률
- **MicroLED**: 애플 워치·AR기기 탑재 시점 — 2027년 전망
- **폴더블**: 보급형 확산 여부 — 삼성 Z폴드 가격 인하

### 추적할 신호

| 신호 | 의미 |
|------|------|
| 중국 BOE OLED 수율·가격 | 삼성·LG 마진 압박 강도 |
| 애플 OLED 아이패드·맥북 발주 | 국내 디스플레이사 수혜 |
| MicroLED 특허 동향 | 차세대 기술 선점 상황 |
| 삼성디스플레이 투자 공시 | 신규 라인 증설 시그널 |

### 관련 기업 (볼트 내)
삼성전자 (삼성디스플레이 모회사), Apple (수요 측)

### 데이터 소스

## 9. 자동차

전동화는 가속보다 재편 중. SDV(소프트웨어 정의 차량)가 다음 경쟁축.
자율주행은 레벨3 이상에서 보험·법규 벽이 실질 진입 장벽.

### 지금 중요한 이유

- **SDV**: 테슬라 FSD vs 현대 CCnV vs 중국 화웨이 플랫폼
- **전기차 캐즘**: 대중 시장 침투 속도 기대치 재조정 중
- **BYD 가격 공세**: 글로벌 저가 EV 공세 → 현대·기아 수익성 압박

## 10. 우주·방산

### 투자 논거

LEO(저궤도) 위성 통신이 **AI 데이터 인프라의 마지막 연결고리**.
방산은 지정학 리스크가 지속되는 한 구조적 수요.
한국은 방산 수출 신흥 강국으로 부상 중.

### 지금 중요한 이유

- **Starlink 독점 구도**: AST SpaceMobile·아마존 Kuiper가 도전 중
- **정찰위성**: 우크라이나 전쟁에서 민간 위성 데이터의 군사 활용 입증
- **한국 방산**: K2전차·K9자주포·FA-50 수출 → 한화에어로스페이스·LIG넥스원
- **드론 전쟁**: 저비용 드론이 첨단 무기 체계를 압도하는 새로운 전쟁 방식

### 추적할 신호

|------|------|
| SpaceX 발사 빈도 | 위성 인프라 확장 속도 |
| NATO 국방비 증액 서약 이행률 | 방산 수요 지속성 |
| 한국 방산 수출 계약 공시 | 국내 방산주 실적 |
| 드론 규제 완화 동향 | 민간 드론 시장 |

### 관련 기업 (볼트 내)

## 11. 로보틱스

### 투자 논거

LLM이 Physical AI의 두뇌가 되면서 로봇의 범용화 가능성이 처음으로 현실화됐다.
2026~2028년이 휴머노이드 로봇의 첫 상용 배치 시점.

### 지금 중요한 이유

- **피지컬 AI**: NVIDIA의 Isaac, 구글 DeepMind RT-2 → 로봇이 자연어 지시를 이해
- **공급망 주목**: 액추에이터(하모닉드라이브)·BLDC모터·6축 IMU 센서
- **경쟁 구도**: Tesla Optimus vs Boston Dynamics vs Figure vs 중국 로봇 (Unitree)
- **산업 수요**: 공장 자동화 (물류·조립) → 인건비 상승 대안

### 추적할 신호

| 신호 | 의미 |
|------|------|
| Tesla Optimus 공장 배치 대수 | 상용화 진행 속도 |
| NVIDIA 로보틱스 플랫폼 파트너사 | 생태계 구축 현황 |

## 12. 양자컴퓨팅

### 투자 논거

현재는 투자 시점이 아닌 **모니터링 시점**이다.
단, PQC(포스트 양자 암호) 전환은 확정된 사이클 — 관련 사이버보안 기업은 현재 수혜.

### 지금 중요한 이유

- **NISQ 한계**: 현재 양자컴퓨터는 노이즈가 많아 실용 계산 불가 (1000 qubit 필요)
- **오류 수정**: 논리 큐비트 1개에 물리 큐비트 1000개 필요 — 2030년 이전 상용화 어려움
- **PQC 수혜**: NIST 양자 내성 암호 표준화 완료 → 사이버보안 기업 전환 특수
- **구글·IBM 경쟁**: 큐비트 수보다 오류율 감소가 실질 지표

### 추적할 신호

| 신호 | 의미 |
|------|------|
| 구글·IBM 논리 큐비트 오류율 발표 | 실용화 가능 시점 |
| NIST PQC 표준 기업 채택 일정 | 사이버보안 전환 수요 |
| 정부 양자 R&D 예산 | 인프라 투자 흐름 |

### 관련 기업 (볼트 내)
Google/Alphabet (Willow 양자칩), IBM

### 데이터 소스
arXiv (quant-ph), Google Blog RSS, Hacker News API
