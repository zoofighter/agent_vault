# 심층 분석 전략 — 대상 & 우선순위

매일 큐레이팅은 넓게 훑는다. 심층 분석은 **좁고 깊게** 판다.
무엇을 대상으로, 언제, 어떻게 깊게 볼 것인지를 정리한다.

---

## 심층 분석의 세 가지 대상

### 1. ★★★★★ 기사 — 본문 전체 읽기

현재 스니펫(200자)만 보기 때문에 놓치는 정보가 많다.

```
현재: "씨티, 삼성전자 목표가 46만원으로 상향" (50자)
      → 왜 상향했는지 알 수 없음

심층: 기사 본문 전체 (1,000~3,000자) → LLM에 전달
      → HBM 수요 회복인지, 파운드리 수율 개선인지, 환율 효과인지 판단 가능
```

**트리거 조건:** 벡터 거리 기반 별점 ★★★★★인 기사만 선택적으로 본문 스크래핑.
전체 기사가 아닌 상위 기사만 읽으므로 비용과 시간을 절약한다.

**구현:** `src/scraper/` — BeautifulSoup → Playwright 폴백 (`CLAUDE.md` Phase 3 설계)

---

### 2. 누적 큐레이팅 — 과거와의 비교

단일 날짜 분석의 한계는 **변화를 못 잡는다**는 것이다.

```
5월 1일  큐레이팅: "파업 리스크 언급"
5월 7일  큐레이팅: "파업 리스크 언급"
5월 13일 큐레이팅: "파업 리스크 언급"
         ↓
심층 분석: "파업 리스크가 3주 연속 등장 → 핵심 변수로 격상
           주가 영향은 아직 제한적 → 선반영 가능성 낮음"
```

`Curated/` 폴더에 날짜별 파일이 축적되면 즉시 구현 가능하다.
LLM에게 오늘 파일 + 과거 N개 파일을 넘겨 "무엇이 달라졌는가"를 물으면 된다.

**효과:**
- 리스크의 지속성 추적 ("3회 연속 언급 → 핵심 변수로 격상")
- thesis 강화/약화 흐름 파악
- 단발성 노이즈와 구조적 변화 구분

---

### 3. 트리거 이벤트 — 특정 회사 전체 심층 분석

매일 실행이 아닌 **의미 있는 변화가 있을 때만** 실행한다.

> [!info] 트리거 조건 (`docs/personal-analyst-report.md` 참조)
> - 주가 ±5% 이상 단일 이동
> - 실적 발표 / 가이던스 변경
> - 경쟁사 주요 발표
> - 규제·정책 결정
> - 큐레이팅에서 thesis 약화 신호 3회 연속

트리거 발생 시 해당 회사에 대해 깊게 파고든다:
- 관련 기사 본문 전체 수집
- 재무 데이터 (주가, PER, 52주 위치, 외인/기관 수급)
- 과거 큐레이팅 맥락
- → **개인 애널리스트 보고서** 생성 (`Memos/analyst-YYYY-MM-DD.md`)

---

## 우선순위

| 순서 | 대상 | 구현 난이도 | 임팩트 |
|------|------|------------|--------|
| **1순위** | ★★★★★ 기사 본문 스크래핑 | 중 (scraper 구현) | 즉각적, 매일 반영 |
| **2순위** | 과거 큐레이팅 비교 | 하 (파일 읽기 + 프롬프트) | Curated 파일이 쌓일수록 가치 증가 |
| **3순위** | 트리거 이벤트 심층 분석 | 상 (재무 데이터 + 보고서 생성) | 투자 결정 품질 직접 향상 |

> [!tip] 가장 빠른 시작
> 1순위 — ★★★★★ 기사만 본문 스크래핑하면 나머지 구조(Analyzer, Curator)는 그대로 쓰면서 입력 데이터 품질만 올라간다.

## LLM 선택 가이드 (심층 분석 시)

| 용도 | 모델 | 이유 |
|------|------|------|
| 기사 본문 읽기 (1~3건) | Groq llama-3.3-70b | 빠름, 한국어 준수, 저비용 |
| 과거 큐레이팅 비교 | Groq llama-3.3-70b | 긴 컨텍스트 필요 (128K) |
| 트리거 이벤트 보고서 | claude-sonnet-4-6 | 복잡한 다단계 추론, 최고 품질 |
