# CLAUDE.md 란 무엇인가

## 역할

매 대화 세션마다 Claude는 기억이 초기화된다. CLAUDE.md는 그 공백을 채워주는 **자동 컨텍스트 파일**이다.

```
세션 시작
    ↓
Claude가 CLAUDE.md 자동 읽기
    ↓
프로젝트 구조 / 규칙 / 스타일을 이미 알고 있는 상태로 작업 시작
```

---

## 우선순위 (계층 구조)

| 파일 위치 | 적용 범위 |
|-----------|---------|
| `~/.claude/CLAUDE.md` | 모든 프로젝트에 전역 적용 |
| `프로젝트루트/CLAUDE.md` | 해당 프로젝트에만 적용 |
| `src/CLAUDE.md` | 해당 폴더 작업 시 추가 적용 |

여러 파일이 있으면 **모두 합쳐서** 읽는다.

---

## 담을 수 있는 내용

- 프로젝트 구조와 모듈 역할 설명
- 자주 쓰는 명령어
- 코딩 규칙 (언어, 스타일, 금지사항)
- 행동 지침 ("확인 없이 진행해라", "한국어로 답해라")
- 기술 스택 요약

---

## settings.json과의 차이

| | CLAUDE.md | settings.json |
|--|-----------|--------------|
| 역할 | **Claude의 행동 지침** (무엇을 알고, 어떻게 행동할지) | **시스템 권한** (어떤 툴 호출을 허용할지) |
| 형식 | 자연어 마크다운 | JSON 규칙 |
| 예시 | "한국어로 답해라" | `"Bash(python:*)"` |

요약: **settings.json은 허용 목록, CLAUDE.md는 행동 설명서**

---

## 이 프로젝트의 CLAUDE.md 파일

| 파일 | 내용 |
|------|------|
| `~/.claude/CLAUDE.md` | 전역 — 파일/명령 자동승인, 한국어 응답, 작업 스타일 |
| `프로젝트루트/CLAUDE.md` | 시스템 개요, 구현 현황표, 기업관리 명령어, 기술스택 |
