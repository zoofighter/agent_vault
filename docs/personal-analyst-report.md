# 개인 애널리스트형 보고서

---

## 세 가지 보고서 비교

| | 뉴스 큐레이션 | 장마감 보고서 | 개인 애널리스트 보고서 |
|---|---|---|---|
| **핵심 질문** | 무슨 일이? | 시장이 어떻게? | ==내 판단은?== |
| **데이터** | 뉴스 텍스트 | 주가·거래량 | 뉴스 + 시장 + 재무 + 과거 기록 |
| **관점** | 필터 | 측정 | **판단·결론** |
| **출력** | 테마 목록 | 수치 요약 | **투자 의견 + 근거 + 액션** |
| **주기** | 매일 | 장 마감마다 | 의미 있는 변화 있을 때 |

> [!important] 핵심
> 애널리스트 보고서는 "나는 어떻게 할 것인가"에 답한다.
> 뉴스 큐레이션과 장마감 보고서는 그 판단을 위한 **재료**다.

---

## 보고서 구조

```
## 투자 의견
매수 유지 / 비중 축소 검토 / 관망

## Thesis 상태
[강화됨 / 유지 / 약화됨] — 이유 한 줄

## 핵심 변화
오늘 새로 알게 된 것 중 판단을 바꿀 만한 것

## 가격 레벨
현재가 / 목표가 / 손절선

## 다음 촉매
언제 / 무슨 이벤트 / 어떻게 될지
```

---

## 현재 시스템과의 차이 — 누적

지금 시스템은 오늘 뉴스만 본다. 애널리스트 보고서는 **누적된 맥락**을 종합한다.

```
내가 왜 이 주식을 샀는지   →  Memos/
지난 큐레이팅 맥락         →  Curated/ (날짜별 축적)
실제 시장 반응             →  장마감 데이터
        │
        ▼
"내 판단이 맞고 있는가?" 를 주기적으로 업데이트
```

> [!note] Obsidian 볼트 구조와의 연결
> `Memos/`, `Research/`, `Curated/` 폴더가 쌓이면
> 세 가지 재료가 자동으로 갖춰진다.
> LLM이 이를 종합해 애널리스트 보고서를 생성할 수 있다.

---

## 생성 조건

의미 있는 변화가 있을 때 트리거:

- 주가 ±5% 이상 단일 이동
- 실적 발표 / 가이던스 변경
- 경쟁사 주요 발표
- 규제·정책 결정
- 큐레이팅에서 thesis 약화 신호 3회 연속
