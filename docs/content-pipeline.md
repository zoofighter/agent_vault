# AgentVault 콘텐츠 파이프라인

> AgentVault가 생성한 분석 노트를 원료로, 블로그 글과 유튜브 스크립트를 자동 생성하는 확장 레이어

---

## 1. 현실성 검토

### 이미 갖춰진 것

AgentVault Daily 노트는 이미 다음을 자동 생성한다:

```
## 오늘의 핵심 뉴스 TOP 3     ← 콘텐츠 도입부로 바로 사용 가능
## 오늘의 핵심 테마            ← 본론 구조로 사용 가능
## 투자 시사점                 ← 결론으로 사용 가능
## 논거 검증                   ← 차별점 (일반 뉴스에 없는 관점)
## 리스크 업데이트             ← 균형 잡힌 시각 제공
```

**결론**: Daily 노트 → 블로그 초안은 구조 변환 수준. 추가 LLM 호출 최소화로 구현 가능.

### 추가로 필요한 것

| 콘텐츠 | 추가 필요 요소 |
|--------|-------------|
| 블로그 | 독자 친화적 문체 변환, SEO 키워드 삽입, 썸네일 제목 |
| 유튜브 스크립트 | 구어체 변환, 시각 자료 큐 삽입, 인트로/아웃트로 |
| 유튜브 영상 | TTS/음성, 슬라이드 또는 AI 아바타 (별도 툴 필요) |

### 현실적 제약

| 항목 | 판단 |
|------|------|
| 블로그 글 자동 생성 | 가능 — 현재 스택으로 즉시 구현 |
| 유튜브 스크립트 생성 | 가능 — 블로그와 동일 파이프라인, 문체만 다름 |
| 유튜브 영상 자동 생성 | 가능하나 외부 툴 필요 (ElevenLabs TTS + 슬라이드 생성) |
| 자동 포스팅 | 블로그는 API 제공 시 가능. 유튜브 자동 업로드는 별도 인증 |
| **투자 조언 법적 문제** | **주의 필요** — 금융 투자 권유로 해석될 수 있음 |

## 2. 콘텐츠 유형

### Type A — 기업 Daily 브리핑 (가장 쉬움)

**원료**: 단일 기업 Daily 노트 1개
**형식**: "오늘의 삼성전자 — 핵심 3가지"
**분량**: 블로그 600~800자 / 유튜브 3~5분 스크립트
**빈도**: 매일, 기업별

예시 제목:
- `삼성전자 오늘 뭔 일 있었나 — 2026-05-14`
- `SK하이닉스 HBM4 소식 정리`

---

### Type B — 주간 섹터 리포트 (핵심 콘텐츠)

**원료**: 한 주 Daily 노트 × 관련 기업 전체
**형식**: "이번 주 반도체 섹터 핵심 흐름"
**분량**: 블로그 1,500~2,000자 / 유튜브 8~12분 스크립트
**빈도**: 매주 일요일

예시 제목:
- `이번 주 AI 반도체 판도 변화 — HBM vs CXL`
- `전기차 배터리 주간 브리핑 — CATL·BYD·LG엔솔`

---

### Type C — 기업 심층 분석 (Research 노트 기반)

**원료**: Research 폴더 PDF 요약 + 관련 Daily 노트 축적분
**형식**: "삼성전자 HBM 경쟁력 완전 정리"
**분량**: 블로그 2,500~3,500자 / 유튜브 15~20분 스크립트
**빈도**: 월 1~2회, 중요 이벤트 시

예시 제목:
- `TSMC 2nm vs 삼성 GAA — 파운드리 대전 2026`
- `엔비디아 Blackwell 공급망 완전 분석`

---

### Type D — 테마 크로스 분석 (차별화 콘텐츠)

**원료**: 여러 기업 Daily 노트에서 공통 키워드 클러스터링
**형식**: "AI 데이터센터 수혜주 총정리"
**빈도**: 테마 급등 감지 시 (Commander Agent 연동)

---

## 3. 새 에이전트: Content Writer Agent

```
AgentVault Daily/Research 노트
          │
          ▼
  ┌── Content Curator ──┐
  │  어떤 노트가         │   오늘 가장 중요한 기업/테마 선택
  │  콘텐츠감인가 판단   │   뉴스 볼륨, 유사도 점수 기준
  └────────┬────────────┘
           │
           ▼
  ┌── Script Writer ────┐
  │  블로그 초안         │   문체: 정보형 블로그 or 구어체 스크립트
  │  유튜브 스크립트     │   Cloud LLM (Claude API) 사용
  └────────┬────────────┘
           │
           ▼
  ┌── Publisher ────────┐
  │  초안 저장           │   Obsidian Content/ 폴더
  │  (선택) 자동 포스팅  │   Tistory / Naver Blog / Substack
  └────────────────────┘
```

---

## 4. LLM 역할 분담

| 단계 | LLM | 이유 |
|------|-----|------|
| 콘텐츠감 판단 (Curator) | Local (llama3.2) | 빠른 분류, 비용 없음 |
| 블로그/스크립트 초안 | Cloud (Claude API) | 자연스러운 문체, 한국어 품질 |
| SEO 제목 5개 생성 | Cloud (Claude API) | 클릭률 최적화 |
| 썸네일 문구 | Cloud (Claude API) | 짧고 강한 표현 |

## 7. 유튜브 영상 자동화 (선택적 확장)

스크립트 생성 이후 영상 제작 자동화 옵션:

| 방식 | 툴 | 장단점 |
|------|-----|-------|
| TTS + 슬라이드 | ElevenLabs + python-pptx | 저비용, 직접 제어 |
| AI 아바타 | HeyGen / D-ID | 자연스러움, 월 구독 비용 |
| 직접 녹화 | 스크립트만 생성 | 최고 품질, 시간 투자 필요 |

**권장**: 1단계는 스크립트 생성만. 영상은 직접 녹화하거나 추후 TTS 자동화.

## 8. 자동 포스팅 가능 플랫폼

| 플랫폼 | API | 비고 |
|--------|-----|------|
| Tistory | REST API 제공 | 카카오 인증 필요 |
| Naver Blog | 제한적 API | 자동화 어려움 |
| Substack | 비공개 API | 비공식 방법 존재 |
| Medium | 공개 API | 영문 콘텐츠에 적합 |
| WordPress | REST API | 자체 호스팅 시 완전 자동화 |
| GitHub Pages | git push | 마크다운 그대로 사용 |

**권장**: 초기에는 Obsidian Content/ 폴더에 초안 저장 → 수동 검토 후 포스팅.
자동 포스팅은 콘텐츠 품질 검증 후 도입.

---

## 9. 법적·윤리적 고려사항

| 항목 | 내용 | 대응 |
|------|------|------|
| 투자 권유 금지 | 특정 종목 매수/매도 권유는 금융투자업 라이선스 필요 | 모든 콘텐츠에 면책 문구 자동 삽입 |
| 뉴스 저작권 | 기사 원문 직접 인용 불가 | 요약·분석 형태로만 사용 |
| LLM 생성 콘텐츠 표기 | 플랫폼별 AI 생성 콘텐츠 정책 확인 | "AI 보조 작성" 표기 권장 |
| 사실 검증 | LLM 환각 위험 | 사용자 최종 검토 단계 필수 |

## 10. 파일 구조

```
src/content/
├── curator.py       # 콘텐츠감 판단, 소재 선택
├── writer.py        # 블로그/스크립트 초안 생성
└── publisher.py     # 파일 저장 + (선택) API 포스팅

볼트/Content/
├── Blog/
│   ├── 2026-05-14_삼성전자-HBM4.md
│   └── 2026-05-11_주간-반도체-리포트.md
└── YouTube/
    ├── 2026-05-14_삼성전자-스크립트.md
    └── 2026-05-11_주간-반도체-스크립트.md

run_content.sh       # 독립 실행
```

## 11. 구현 로드맵

| 단계 | 내용 | 난이도 |
|------|------|--------|
| **v1** | Daily 노트 → 블로그 초안 자동 생성, Obsidian 저장 | 낮음 |
| **v2** | 주간 섹터 리포트 자동 생성 | 낮음 |
| **v3** | Tistory/Substack 자동 포스팅 | 중간 |
| **v4** | 유튜브 스크립트 + TTS 영상 자동 생성 | 높음 |

**v1 예상 구현 시간**: 1~2일. Daily 노트가 이미 구조화되어 있어 프롬프트 설계가 핵심.

## 12. AgentVault 전체 구조에서의 위치

```
[기존] AgentVault 6개 에이전트
  Memory → Scout → Filter → Analyst → Scribe → Research
                                                    │
                                                    ▼
                              [신규] Content Writer Agent
                               Curator → Writer → Publisher
                                              │
                                    블로그 / 유튜브 스크립트
```
