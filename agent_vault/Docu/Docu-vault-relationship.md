# Docu와 Vault 정보 레이어 관계

> AgentVault 안의 5가지 정보 레이어가 어떻게 연결되어 투자 판단으로 이어지는가.

---

## 5개 레이어 개요

```
Docu/          → 불변하는 기술 구조 지식 (내가 채우는 교과서)
Research/      → 전문가의 분석 (증권사·IR 리포트)
Daily/         → 오늘의 신호 (에이전트가 수집한 뉴스)
Memos/         → 나의 판단과 가설 (내가 쓰는 투자 노트)
Digest/        → 시스템 행동 기록 (에이전트 액션 로그)
```

---

## 레이어별 역할

### Docu/ — 배경 지식 베이스

- **무엇**: 섹터별 기술·산업 구조 문서. 잘 바뀌지 않는 구조적 지식.
- **누가 쓰나**: 사람이 직접 채운다 (AI가 골격 제공).
- **언제 읽나**: 뉴스를 이해하기 전, 섹터를 처음 공부할 때.
- **핵심 가치**: "CoWoS 뉴스"를 봤을 때 Docu의 `3.4 첨단 패키징` 챕터가 없으면 임팩트를 모른다.

```
Docu/반도체/반도체_TechDoc.md
  └─ 3.4 첨단 패키징
       └─ 3.4.2 CoWoS 구조 [내가 채운 내용]
            ↑
            이 지식이 있어야 오늘의 "TSMC CoWoS 캐파 부족" 뉴스가 보인다
```

---

### Research/ — 전문가 시각

- **무엇**: 증권사 리포트, 기업 IR, PDF 요약. 특정 시점의 애널리스트 분석.
- **누가 쓰나**: AgentVault Research Agent가 자동 수집·요약. 로컬 LLM(Ollama) 요약.
- **언제 읽나**: 특정 기업의 깊은 분석이 필요할 때. Docu의 플레이어 섹션을 채울 때.
- **핵심 가치**: "삼성전자 18A 수율 이슈" — 증권사 리포트가 수치를 제공한다.

```
Companies/KR/삼성전자/Research/
  └─ 20260511_2Q26 영업이익 100조원 예상.md
       └─ 애널리스트 근거·수치 → Docu 5.2 삼성전자 챕터로 흡수
```

---

### Daily/ — 오늘의 신호

- **무엇**: AgentVault가 매일 수집·필터링한 뉴스. 볼트 문맥 기반 유사도 필터 통과한 기사만.
- **누가 쓰나**: Scout → Filter → Analyst → Scribe 에이전트 자동 생성.
- **언제 읽나**: 매일 아침/저녁 Telegram 브리핑 + Obsidian에서 직접.
- **핵심 가치**: 수백 건의 뉴스 중 내 볼트(내가 관심 있는 기업·기술)와 관련된 것만 올라온다.

```
Companies/US/NVIDIA/Daily/2026-05-15a.md
  └─ "TSMC CoWoS 납기 8주 → 6주 단축" ★★★★
       └─ Docu의 CoWoS 지식 없으면 ★★★★의 의미를 모른다
```

---

### Memos/ — 나의 가설과 판단

- **무엇**: 내가 직접 쓰는 투자 노트. 시스템이 절대 덮어쓰지 않는 유일한 공간.
- **누가 쓰나**: 사람만.
- **언제 쓰나**: Daily 뉴스 + Research를 읽고 내 판단이 형성될 때. 투자 전·후 기록.
- **핵심 가치**: ChromaDB에 임베딩되어 **이후 뉴스 필터의 기준**이 된다. 내가 더 쓸수록 필터가 정교해진다.

```
Companies/US/NVIDIA/Memos/HBM_thesis.md
  "HBM 공급 병목이 2026 하반기까지 지속될 것으로 봄.
   근거: SK하이닉스 HBM3E 가동률 95% + TSMC CoWoS 대기 6주"
       ↑
       이 메모가 ChromaDB에 들어가면
       → 이후 "HBM 공급" 관련 뉴스의 유사도 점수가 올라간다
```

---

### Digest/ — 시스템 행동 기록

- **무엇**: Commander·Briefing·TechReport 등 에이전트의 실행 로그. Obsidian callout 블록.
- **누가 쓰나**: 에이전트 자동 기록.
- **언제 읽나**: 에이전트가 어떤 판단을 내렸는지 추적할 때.

---

## 정보 흐름 — 투자 판단까지

```
                    [배경 지식]
                    Docu/반도체
                    3.4 CoWoS
                         │ 해석 맥락 제공
                         ▼
[오늘의 신호]      [전문가 시각]
Daily/NVIDIA       Research/TSMC
"CoWoS 납기 단축"  "CoWoS 캐파 20% 증설"
         │              │
         └──────┬───────┘
                ▼
         내가 종합 판단
         (Docu 지식 + 오늘 뉴스 + 전문가 분석)
                │
                ▼
         Memos/에 기록
         "TSMC CoWoS 정상화 → NVIDIA GPU 공급 개선 → 수혜"
                │
                ▼ (ChromaDB 임베딩)
         이후 관련 뉴스 필터 정교화
                │
                ▼
         Commander 액션 명령
         "NVIDIA 비중 확대 검토"
                │
                ▼
         Telegram 알림
```

## 레이어 간 상호작용 요약

| 방향 | 흐름 | 메커니즘 |
|------|------|---------|
| Docu → Daily 해석 | 지식이 신호를 읽는 눈이 된다 | 사람의 독해력 향상 |
| Research → Docu | 전문가 수치·분석을 기초 지식에 흡수 | 사람이 복사·요약 |
| Daily → Memos | 오늘 뉴스가 내 판단을 업데이트 | 사람이 기록 |
| Memos → Daily 필터 | 내 메모가 다음 뉴스 수집 기준 | ChromaDB 임베딩 |
| Daily → TechReport | 이슈 감지 → 심층 리포트 트리거 | Commander Phase 2 (예정) |
| Docu → TechReport | 배경 섹션 참조 | Phase 4 LangGraph (예정) |

## 비유로 이해하기

```
Docu       = 의대 교과서    (해부학·생리학 — 바뀌지 않는 구조)
Research   = 전문의 소견서  (특정 환자·시점의 전문 분석)
Daily      = 의료 차트      (매일 바이탈 기록 — 오늘의 상태)
Memos      = 나의 임상 일지 (내 판단·가설·치료 계획)
Digest     = 병동 간호 기록 (시스템이 뭘 했는지)
```

차트(Daily)만 읽어서는 치료할 수 없다.
교과서(Docu) 지식이 있어야 차트의 이상 수치가 위험한지 안다.

---

## Docu 작성 원칙

1. **구조가 먼저, 내용은 나중** — 목차(골격)를 먼저 완성하고 섹션별로 채워간다
2. **에이전트 뉴스 → Docu 흡수** — Daily/Research에서 중요한 사실을 발견하면 해당 Docu 섹션에 추가
3. **TechReport → Docu 검증** — 에이전트가 생성한 TechReport를 Docu와 대조해서 오류 수정
4. **날짜 기록** — 섹션 내용을 추가할 때 `(2026-05-15 기준)` 메모
